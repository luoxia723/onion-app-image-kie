# 画面叙事与关系规划

把“想表达什么”转成“观众实际看见什么”，再把能同时成立的画面决定写成提示词。服务于文生图、带资产参考的图生图和连续图片设计；输出设计与Prompt，不自行调用生成服务。被业务Skill调用时，先读取它的固定项和输出合同。

## 输入与职责

读取确认文案、功能事实、目标人群、图片数量与顺序、投放形态、选定画风或分配规则、参考资产及用户固定项。区分已知事实与创作空间：可以创作地点、道具、人物表演和视觉隐喻；产品能力、数字、承诺与真实界面内容由确认资料决定。

人物是否必需、是否使用IP、CTA、品牌位置、系列依赖、生成模型与费用规则由业务合同决定。本Skill不把某个品牌的人物要求、时代、画风池或手机场景推广为所有任务的通用要求。缺少决定真实性或执行范围的信息时定向补问，其余美术选择可自行完成。

按执行职责保存约束：代码处理参数、素材绑定、路径、依赖和导出；计划保存设计依据；模型Prompt写具体画面与必要的视觉保真要求；成图检查验证实际结果。素材路径正确不能代替Logo、字体或角色保真的绘图指令。

## 先定视觉语言，再把叙事落到可见证据

1. 先确定画风来源，具体到造型、线面、空间和材料表现。用户或业务已经分配的画风直接使用。把其余时代、场景、故事、镜头、光色作为一个整体设计，避免分别抽签造成偶然拼接。
2. 为画风选择能容纳当前内容的世界与具体地点。建筑、服饰、道具与光线共同建立世界；跨时代产品若是创意的一部分，明确其叙事用途。
3. 为每张确定一句传播任务和一个值得定格的瞬间。把抽象痛点与产品帮助转成表情、视线、姿态、动作、物体状态等可见证据。“焦虑”“效率提升”本身不算画面证据。
4. 联合设计人物动作、物体接触与支撑、镜头可见面、构图和阅读路线。最后统一光色、材质及装饰密度，并核对所选画风真正支配了人物和场景。

痛点用符合文案的具体处境表达，避免夸张羞辱、擅加诊断或编造效果。只承诺“安排任务”时，可见变化可以是找到起点、开始操作；不据此画出高分、排名或夸大的成功结果。某张负责呈现困难时，保留该阶段的情绪和状态，不提前演完后续解决过程。

## 每张的内部场景草案

利用业务已有字段保存这些决定，已有内容写清即可；没有结构要求时用简短设计记录。不把下面的检查表逐项粘进模型Prompt。

| 决定 | 记录什么 |
|---|---|
| 传播任务与证据 | 当前文案要传达什么，哪几个实际可见的变化支撑它 |
| 主体与瞬间 | 谁在何处，正在进行哪个动作，处于怎样的情绪或任务阶段 |
| 关键交互 | 谁用哪只手拿什么、触碰哪里、看向哪里；人物与道具由什么承托 |
| 镜头与空间 | 景别、视角、可见面、前后遮挡；需要被读懂的脸、手、界面是否能同时看见 |
| 信息与资产 | 标题、产品信息、CTA和品牌的位置与层级；每张参考图的身份、保留项与可改项 |
| 系列变化 | 同套固定哪些设定，本张改变哪些动作、状态或文字 |

只展开当前画面涉及的关键关系。站立人物、静物广告、双人互动、手持设备各有不同关系，不给每张机械增加“握笔、手机、桌面”模板。

## 动作与镜头必须相容

先用主体—动作—对象理清交互，再补影响画面成立的接触、支撑和遮挡，最后从镜头位置检查能否看见传播证据。描述“右手握笔，笔尖接触练习册，练习册平摊在桌面”比一句“符合真实物理规律”提供更多可执行信息。

特别检查同一只手承担的动作是否相容、道具是否有支撑、目光是否指向目标、屏幕正反面与机位是否一致。不要求模型展示被身体或其他物体完全遮挡的关键内容。可通过换机位、放下道具、改变拿法或简化次要动作解决冲突，保留当前传播任务。

例如需要学生读手机且观众能看清屏幕时，可让手机立在桌面支架上、屏幕朝学生，镜头从学生侧后方越肩观察，呈现侧脸、手和屏幕。需要正面完整表情时可换取景或调整设备位置。机位由当前证据决定，越肩只是其中一个方案，不固定所有画面。

## 单图与系列

单图把内容凝聚到同一瞬间，通过画面内的关系概括故事；避免把一帧写成先后发生的多段动作。同一张可以有前后状态的视觉线索，但主要人物只有一个正在发生的动作状态。

双图、三图按确认文案分配叙事责任。困难→行动、选择→结果、目标→帮助→推进都是可选结构，实际顺序服从每张文案。每张要有可见变化，不能只替换标题；同套人物身份、世界、画风、品牌与字体保持连续，需要变化的机位或动作局部调整。系列是分别生成的独立图片，是否拼版由业务合同决定。

若分支使用已生成首张，先检查首张实际形成的姿态和空间，再写分支的保留与改变。首张与最初意图有差异时记录偏差；不要用一句“保持一致”强行继承错误，也不在没有授权时自行重新付费生成。

## 参考图按身份使用

为每次请求的每张参考图说明用途：Logo、角色、字体、真实UI、风格、构图或已生成完整画面。编号按实际请求重新确认。Logo和字体素材各自只约束对应元素；画风来自用户指定或本轮画风选择，不能默认从这些局部资产继承整幅美术风格。

完整画面参考可提供世界、角色、字体、品牌位置与空间连续性；明确本张继承哪些，修改哪些。局部原版资产仍由业务合同规定使用和校验，不擅自新增参考图、改变分支依赖或改成后期贴图方案。

## 编写最终Prompt

按业务原有格式编排。要求一段式时，用正向自然语言连起画风、具体场景、人物瞬间与关键关系、镜头构图、光色、逐字文案和素材用途。内部计划可以结构化，最终不输出场景图、推导过程、字段清单或负面提示段。

保留影响结果的必要约束，只合并重复描述，不设通用字数上限。主副文案、按钮与界面文字根据各自用途交代；原版Logo、字体与IP的识别要点继续写清楚。增加关键关系不能挤掉品牌、文案、CTA、事实边界和系列替换要求。

## 分开检验设计与成图

生成前检查：每张文案是否有可见证据；动作与机位能否同时成立；参考用途和固定项是否准确；同套动作是否递进；最终Prompt是否保留适用的视觉约束。发现冲突先修计划与文字，不用更多空泛形容词掩盖。

生成后检查：文字与品牌、角色身份、动作接触与支撑、镜头可见面、叙事阶段、风格和缩小后阅读是否达成。逐张记录实际偏差，并按业务候选流程展示、选择或修复。静态校验与指令完整不等于画面正确；本方法不保证消除模型的结构和保真错误。
