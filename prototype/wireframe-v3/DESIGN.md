# 灰度结构设计说明（wireframe-v3）

## 1. 六个画面的唯一主角与唯一主动作
- **`#config`（信息流 · 单图配置）**：唯一主角是「渠道锁定的文案与对齐版位列表」；唯一主动作是「开始生成」（紧邻实时汇总「共 21 张」）。
- **`#config-app3`（应用商店 · 三图配置）**：唯一主角是「应用商店三图形式下的 3 句文案与 4 个三图版位」；唯一主动作是「开始生成」（紧邻「共 24 张」）。
- **`#config-custom`（定制画面展开）**：唯一主角是「三栏参考图上传位与提炼要点（含『添加要点』动作）」；唯一主动作是「开始生成」（局部确认动作为「确认」）。
- **`#workbench`（信息流 · 单图工作台）**：唯一主角是「当前版位 3 套等比并排大图画布」；唯一主动作是「保存已合格的 4 套」（与左侧 7 个信息流版位目录的实选套数及版位覆盖数严格对齐）。
- **`#workbench-3`（应用商店 · 三图工作台）**：唯一主角是「每套内并排展示图 1 / 图 2 / 图 3 的套系卡片（OPPO 横版三图 320×210 等比无损放大）」；唯一主动作是「保存已合格的 3 套」。
- **`#lightbox`（大图弹层）**：唯一主角是「居中按真实比例放大的单张广告图」；唯一主动作是「选这一套」（次动作为「重出本张」）。

## 2. 渠道优先的配置顺序与版位列表排布
- **渠道优先（单选门控）**：第一行先单选渠道（`应用商店` / `信息流` / `学习机`）。未选渠道前，下方文案、版位、画面设定与右侧生成区整体置灰禁用；选中 `学习机` 时展示占位空态。
- **形式随渠道显隐**：仅 `应用商店` 显示形式分段行（`单图` / `双图` / `三图`）；`信息流` 与 `学习机` 固定为单图，隐藏形式行。
- **文案随形式切换**：单图为 `主标题 + 副标题`；双图为 `句 1 + 句 2`；三图为 `句 1 + 句 2 + 句 3`；全局按钮文字开关与输入框同列排布。
- **紧凑对齐版位行（1280×800 一屏不滚动）**：版位由流式胶囊改为双栏对齐列表行，每行固定四列：`勾选框 · 版位名 · 尺寸 · 尾随状态与按钮下拉（[🔒 Logo] / [立即体验 ▾]）`，8 个信息流版位分 4 行排完，确保 1280×800 视口零纵向滚动。

## 3. 核心状态的布局与样式表达（不靠句子解释）
- **生成中 vs 等图 1（双图 / 三图套卡内区分）**：
  - **已完成**：实线深灰画布框 + 画面标题与按钮模拟块，整套三张均完成时卡片右上角出现勾选框 `✓`。
  - **生成中**：动态感强的 `-45deg` 深浅斜纹背景骨架 + 深色虚线框 + `生成中` 状态短词角标。
  - **等图 1**：图 1 未完成时，图 2、图 3 采用极浅纯白灰底（`#f7f7f7`）+ 细弱浅灰点状虚线框（`1px dotted #bbbbbb`）+ 降低透明度的 `等图 1` 短词，与图 1 的斜纹生成态一眼拉开先后层级。
- **目录「已出齐未选」与「已选」区分**：目录右侧状态固定双列——已出齐且已选显示实心黑底 `✓ 1`；已出齐但未选显示白底细框 `0/3 待选`；生成中显示 `1/3` 进度条；有问题显示 `1 问题` 警示框。
- **强制带 Logo 锁定态**：`喜马拉雅 720×1280` 与 `720×1559` 所在版位行内固定展示深灰只读胶囊 `[🔒 Logo]`；即使全局切换为「不用 Logo」，这两项仍保持锁定徽章样式，不写解释长句。
- **两类异常就地处理**：仅 `喜马拉雅 1200×480`、`喜马拉雅 720×1559`、`CPA 横图 690×360` 三个版位可出现 `去框失败`（动作：`重新去框` / `整图适配`）；其余版位异常统一显示 `生成失败`，卡片内动作按钮为单一 `补齐`。
