# 灰度结构设计说明（wireframe-v2）

## 1. 四个画面的唯一主角与唯一主动作
- **`#config`（一屏配置）**：唯一主角是「文案与目标版位组合」；唯一主动作是「开始生成」（紧邻实时汇总的「共 21 张」）。
- **`#config-custom`（定制画面展开）**：唯一主角是「三栏参考图上传位与提炼要点」；唯一主动作是「开始生成」（局部确认动作为「确认要点」）。
- **`#workbench`（挑选工作台）**：唯一主角是「当前版位 3 套等比并排大图画布」；唯一主动作是「保存已合格的 4 套」（卡片级主操作为直接点选卡片）。
- **`#lightbox`（大图弹层）**：唯一主角是「居中按真实比例放大的单张广告图」；唯一主动作是「勾选这一套」（次动作为「重出本张」）。

## 2. 相比上一版（`prototype/wireframe/`）删减的文字与元素
- **删掉顶部步骤条与冗余区块序号**：去掉 `① 配置生成 → ② 挑选保存` 及 `1. 2. 3. 4. 5.` 编号；点「开始生成」直达工作台，分组留白已能表达先后关系。
- **删掉配置页「5. 高级（方向名）」折叠区**：方向名由系统自动取主标题，不再暴露给用户配置。
- **删掉功能解释与说教提示**：去掉「按渠道分组，点击标签勾选目标投放尺寸」「每个版位并行生成不同构图与 IP 方案供挑选」「可以离开，回来从侧栏继续」「本机处理，不花钱」「没出完的套，出完可再存」「（点击图片打开大图弹层）」等全部解释性副文案。
- **删掉参考图槽位副标题与冗余说明**：去掉「借配色、笔触、质感」「借主体位置、文字区域」「放进画面里的屏幕，界面文字不改」「已上传风格参考图」「系统整理的要点（点击标签可直接编辑）」「放了风格图，所有套统一用这个风格」，靠槽位标题、标签可编辑形态与锁定徽章自解释。
- **删掉卡片上的文字状态标签**：「已勾选 / 未勾选 / 不可勾选」文字全部移除，改由卡片边框、角标勾号与置灰态直接表达。
- **删掉右侧汇总栏冗余拆解行**：合并「版位 7 个 × 3 套 = 共 21 张」为紧凑控制区，释放横向空间给文案与版位主角。

## 3. 六种状态的布局与样式表达（不靠句子解释）
- **生成中**：卡片内画布用浅灰斜纹/脉冲虚线框骨架（`720×1559`），右上角选择框隐藏，目录项右侧显示 `1/3 ···` 弱化徽章。
- **已选**：卡片采用 `2px solid #111` 粗黑实线边框与深色内描边，右上角实心黑底白勾 `✓` 角标；目录项右侧显示实心深灰 `✓ 1` 徽章。
- **有问题**：卡片采用醒目的双层深色警示边框（`2px solid #111` + 外层虚线框），左上角黑底白字「去框失败」角标，画布底部内嵌「重新去框」「整图适配」两个动作按钮，不写原因长句。
- **不可用**：控件或卡片降低对比度（`opacity: 0.45`，浅灰底 `#efefef`、虚线或浅灰边框 `#ccc`、`cursor: not-allowed`），不加「不可勾选」文字。
- **按参考图锁定画风**：当「参考风格」槽位处于已上传态（实线深框 + 缩略图 + 要点标签组）时，下方画风控件直接变为置灰不可改的只读胶囊 `[🔒 按参考图]`，与参考风格槽形成上下对齐视觉关联。
- **某版位单独改按钮文字**：全局按钮文字旁设开关；已勾选的版位胶囊内嵌尾随小胶囊显示当前按钮文字（默认继承如 `[立即体验]`，点击原地变为内联输入框可改字或点 `×` 设为 `[无按钮]`，改过的胶囊以深色实心底区分）。
