# 视觉方向卡 v1：看样台

> 按 oil-ui「方向卡」整理；结构以已定稿的线框 v3 为准（prototype/wireframe-v3/）。只推荐一个方向。

| 字段 | 选择 |
|---|---|
| 北极星 | **把广告图当成要验收的样张**：界面退到中性灰的看样台后面，图按真实比例摆上台，人只做「看、选、存」三件事。 |
| 主角与主动作 | 配置页：主角是「共 N 张」和版位清单，主动作是「开始生成」。挑选工作台：主角是当前版位并排的各套图，主动作是勾选，之后是「保存已合格的 N 套」。其他动作（再出一套、修改配置）降为描边按钮。 |
| 调性（五个刻度） | 能量偏安静（主角是广告图，界面不和它抢）；完成度精致（看样需要准确的尺寸和对齐）；密度中偏密（一次十几到二十几张图，是工作工具）；分量偏轻，只有计数用重字（呼应 Logo 粗圆的字形）；严肃度居中偏活泼（K12 品牌，但活泼只留给空状态和完成时刻）。 |
| 产品参考与取舍 | 品类：看片 / 选片工具。参考 Lightroom 和 Capture One 的选片界面，以及 Frame.io 的审片界面（**未看图，凭记忆**）。沿用：中性灰底、图按比例排开、只用一个强调色表示选中、目录和计数分开。换掉：深色专业风（运营在白天的办公室里用，深色看久了累）、星级和旗标这类复杂评级（这里只有选或不选）。 |
| 交互参考与取舍 | 选片工具的流程「点图 → 卡片出现选中框 → 计数加一 → 自动跳到下一个」与已定流程一致；键盘操作（空格勾选、← → 切换）照搬，减少鼠标往返。**未看录屏，凭记忆。** |
| 生成引擎 | 借其他领域的表现形式：印刷**看样台**。来自这个产品的证据：用户的核心工作就是验收一批印前样张（尺寸、比例、文字和按钮是否完整），中性灰底能避免背景颜色干扰对广告配色的判断。 |
| 首屏骨架 | 工具类：一排 56px 紧凑顶栏（任务名、已出 n/N、修改配置），下面直接是工作区。挑选工作台分三栏：版位目录 240px，看样台占剩余宽度，底部保存栏 56px。阅读从当前版位的第 1 套开始。 |
| 字体 | 不额外加载字体，本机离线可用：苹方 / 微软雅黑。正文 14px/400；标签和尺寸 12px，等宽数字（tabular-nums）；计数「共 21 张」「已选 4 套」用 28px/700，与正文差两级。 |
| 色彩 | 底色看样灰 `#E9EBEE`；面板白 `#FFFFFF`；文字墨黑 `#11151C`（取自 Logo 字标）；**主强调洋葱蓝 `#0A64FF`**（取自 Logo 外描边），只用于选中、主按钮和焦点；生成中天青 `#1FAEFF`（取自 Logo 主体）；问题琥珀 `#D9822B`，失败红 `#E5484D`；派生：选中底 `#E8F0FF`、描边 `#D5D9DF`、禁用 `#C4C9D0`。品牌色只出现在「选中」和「进行中」两件事上。 |
| 主视觉 | 广告图本身。品牌形象只出现在三处：空状态（没有任务时，洋葱 IP 在看样台边上）、「图包已保存」的完成时刻、侧栏品牌位。 |
| 图标 | 线性图标，1.75px 描边，圆头圆角，呼应 Logo 字标的圆端笔画；只用于勾选、展开、上传、更多这几处，状态用短词，不用图标替代。 |
| 控件语法 | 圆角统一：面板 12px、控件 8px、标签 6px；1px 细描边；选中 = 2px 洋葱蓝外框 + 右上角蓝底白勾；按下缩到 0.98；主按钮是实心墨黑或洋葱蓝，次按钮是白底细描边。 |
| 核心交互 | 在看样台点一套 → 卡片出现蓝框和勾 → 目录里这个版位的「✓ 1」亮起 → 底栏「已选」加一 → 当前版位选够后，0.4 秒后自动滚到下一个版位。 |
| 记忆点 | **显影**：生成中的图位是天青色细噪点在缓慢流动；图片到达时从中心向外显影（约 400ms），对应「出一张亮一张」。**收样**：点「保存已合格的 N 套」后，选中的缩略图依次缩进底栏的图包图标，数字跳到 vNNN。 |
| 资产与技术 | 全部用 CSS 和少量原生 JS 实现，不新增依赖；Logo 和 IP 用仓库里已有的素材。显影效果用 CSS mask 加渐变，不用 canvas。 |
| 动效 | 手感：「嗒」，像把一张样张放到看样台上。三处基本动效：选中（框收拢 120ms）、显影（400ms ease-out）、跳到下一个版位（滚动 300ms），节奏统一偏短促。 |
| 结构性突破 | 看样台用中性灰底，图按真实比例和统一缩放摆放，每张图下方标尺寸，像印刷样张，不再是白卡片网格。 |
| 放弃什么 | 紫蓝渐变、卡片阴影堆叠、满屏彩色状态胶囊、深色模式优先、在工作区里放 IP 装饰、解释性文案。 |
