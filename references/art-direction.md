# 从艺术定调到生成提示词

先冻结本轮确认的文案、功能事实与制作配置，再做艺术决策。目标是让观众迅速读懂一个有吸引力的学习故事。下面是决定的先后关系，不是要求每张图都使用同一版式。

## 1. 画风：决定视觉语言

批量默认先运行画风分配，单图逐张随机、双/三图按套随机，优先不重复；用户指定优先。读所选画风的造型、线面、空间和材料特点，用这些特点支配整张画面，而不只给常规动漫背景贴一层纹理。

## 2. 世界与场景：让画风有发生的地方

先确定时代与世界，再选择具体地点、道具和空间关系。现代家居、古代书院、中世纪藏书室、未来工坊、幻想纸城等都可使用，也可设计有意的跨时代组合；这些只是例子，不是场景池或历史复原要求。背景、建筑、服饰细节和学习道具共同说明世界，不固定为现代书桌或几何舞台。

时代是广告美术设定，不暗示APP在历史上真实存在，也不以场景凭空增加产品功能。若古代场景出现手机，可把跨时代并置作为明确的创意，而不是无意混搭。

## 3. 故事：选择值得定格的一瞬

每张均有人物参与，先写清这位学习者在什么具体处境中遇到什么困难，产品动作如何帮助他推进下一步。有IP使用选定IP，无IP默认使用普通原创初中生。通过姿势、视线、表情与学习动作表现对应文案的痛点或变化，纸张、建筑和路径作为辅助视觉隐喻。

单图选择一个能概括故事的瞬间；双/三图把同一世界中的状态递进写到各自slot_actions，保持同套画风与主体连续。动作要服务对应短句，不只换文案而重复摆姿势。

## 4. 构图：安排观看顺序

决定第一眼看什么、下一眼被什么动作或线索带走，以及最后留下哪个产品信息。按内容选择景别、机位、透视、前中后景和文字留白；让主文案与主视觉形成关系。可以让IP、物件、屏幕、建筑或文字成为视觉中心，不固定“大字加右侧角色”。

按[画面规划的APP适配](scene-planning-app.md)把当前文案落到可见证据，再联合确定姿态、手与道具的接触支撑、目光及镜头可见面。需要人物看屏幕且观众读到界面时，先选能容纳两者的机位与设备位置。把实际决定写进共用prompt或对应slot_actions；内部构图字段不能代替模型输入。单图定格一个瞬间，双/三图逐张推进，各张保留当前阶段的情绪与状态。

## 5. 光色与材质：统一整张画面

根据世界和故事选择光源、时间氛围、主辅色、材质与装饰密度。颜色和材质共同建立情绪、空间与焦点；文案和Logo仍清楚可读。装饰只进入有意义的位置，不遮住关键动作、脸部或文字。

## 6. 主体与产品呈现

无IP时默认使用普通原创初中生参与每张画面的学习故事，面容、体态与日常穿着体现初中阶段的少年感，按所选画风设计人物；用户明确指定其他年龄或人群时按指定执行。不套用品牌IP的身份与服装要求。物件、建筑与抽象图形辅助人物动作和痛点表达。有IP时保留主要识别特征和原服装的核心配色、轮廓，允许少量时代或风格对应的披肩、扣件、纹样、材质与配饰；同套从首张继承这次设定。角色身份、品牌Logo与普通画面装饰各自管理。

屏幕可以清楚显示内容，不再默认模糊。有真实截图且需要忠实还原时用reference模式；没有截图也能用conceptual模式设计清晰示意UI；不需要屏幕时用none模式。示意界面只表达已确认功能，记录为设计示意，不冒称真实截图。Agent可基于确认的功能列出screen_text，例如“今日任务”“学习进度”；这些是屏幕内部文案，不能借此改写广告主文案或增加未经确认的成绩、价格与效果数字。

## 7. 固化设计层级，再写Prompt

新配置默认art_direction_required=true。每套visual_concepts中保留完整prompt和slot_actions，并增加learner_story及艺术定调。learner_story包含protagonist（具体学生或选定IP）、pain_point（对应文案的真实学习困难）、product_action（已确认的帮助）、visible_change（可见的下一步或进度）。四字段用于内部复核，人物描述进入最终画面；痛点、产品动作与变化由Agent融入场景和逐张动作，不重复灌入分析段。艺术定调示例：

```json
{
  "art_direction": {
    "world": "中世纪启发的幻想藏书室，时代作为美术设定",
    "scene": "石拱窗边的长桌、书架和展开的纸页构成空间",
    "story": "散开的学习纸张被整理成清楚的每日任务路径，表达由只有目标到知道下一步",
    "composition": "纸页路径从前景引向主要学习动作，标题位于自然亮面留白，Logo按规定位置",
    "lighting_materials": "窗光形成纸面焦点，石材、木材与纸张采用所选主画风的统一表现"
  },
  "screen_ui_mode": "conceptual",
  "screen_text": ["今日任务", "学习进度"]
}
```

world和scene可以使用任何适合的设定；story必须来自当前功能事实。prompt将这些决定融成完整画面，不机械堆砌关键词。设计层级完整保存在计划中，供追溯和复核。最终prompt把时代、场景、故事、构图和光色合成一段完整明确的画面描述；脚本结合所选画风、该描述和对应slot动作，不重复灌入五层分析原文。

需要屏幕文字时，每张job保存ui_text，等于本套计划screen_text；这些字段供预检和追溯，不作为文字清单写入Prompt。主文案仍使用对应确认原句。

## 最终Prompt是一段正向描述

保持之前的画面叙述方式，将画风、时代、场景、故事、构图和光色提炼成一段话，加入完整文案与实际素材的视觉用途。设计层级是内部推导，不输出五段分析、分节标签、内部编号或文字白名单。只描述希望看到的内容；无IP或不展示屏幕的方案直接描述所选主体，不写排除项。用户广告文案原句保持完整。

提示词以信息完整、指令明确为优先，首张和分支均不设默认字数目标。影响成图的决定和必要约束应充分说明；内容多时可以加长，只合并重复表达。分支仍须写清继承什么、完整替换哪些文案区域、当前人物动作如何对应痛点或学习推进。

## 硬约束与效果判断

艺术自由服从本轮用户选择与[固定项](visual-invariants.md)：原版Logo、已确认广告文案与功能事实、字体开关与参考、渠道尺寸和KB、2.5/1K、蓝框阈值、首张依赖、费用与采纳流程保持原合同。代码可处理的约束在配置、素材校验与导出中落实；影响成图的Logo、字体、角色与生成范围用简短正向语句融入画面描述。

预检确认设计层级保存在计划，逐张动作、确认文案与实际素材用途准确进入一段式Prompt。生成后再看画风是否真正可辨、故事能否读懂、画面是否有吸引力，以及品牌和文字是否准确；字段齐全与测试通过不等于审美通过。
