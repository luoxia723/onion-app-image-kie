# 从艺术定调到生成提示词

先冻结本轮确认的文案、功能事实与制作配置，再做艺术决策。目标是让观众迅速读懂一个有吸引力的学习故事。下面是决定的先后关系，不是要求每张图都使用同一版式。

## 1. 画风：决定视觉语言

批量默认先运行画风分配，单图逐张随机、双/三图按套随机，优先不重复；用户指定优先。读所选画风的造型、线面、空间和材料特点，用这些特点支配整张画面，而不只给常规动漫背景贴一层纹理。

## 2. 世界与场景：让画风有发生的地方

先确定时代与世界，再选择具体地点、道具和空间关系。现代家居、古代书院、中世纪藏书室、未来工坊、幻想纸城等都可使用，也可设计有意的跨时代组合；这些只是例子，不是场景池或历史复原要求。背景、建筑、服饰细节和学习道具共同说明世界，不固定为现代书桌或几何舞台。

时代是广告美术设定，不暗示APP在历史上真实存在，也不以场景凭空增加产品功能。若古代场景出现手机，可把跨时代并置作为明确的创意，而不是无意混搭。

## 3. 故事：选择值得定格的一瞬

用一句话写清：谁或什么主体，正在做什么，遇到什么阻碍，产品动作如何让变化可见。有IP时靠姿势、视线、表情与道具互动推动故事；无IP也可以用物件整理、建筑路径、纸张变化或文字构成叙事。

单图选择一个能概括故事的瞬间；双/三图把同一世界中的状态递进写到各自slot_actions，保持同套画风与主体连续。动作要服务对应短句，不只换文案而重复摆姿势。

## 4. 构图：安排观看顺序

决定第一眼看什么、下一眼被什么动作或线索带走，以及最后留下哪个产品信息。按内容选择景别、机位、透视、前中后景和文字留白；让主文案与主视觉形成关系。可以让IP、物件、屏幕、建筑或文字成为视觉中心，不固定“大字加右侧角色”。

## 5. 光色与材质：统一整张画面

根据世界和故事选择光源、时间氛围、主辅色、材质与装饰密度。颜色和材质共同建立情绪、空间与焦点；文案和Logo仍清楚可读。装饰只进入有意义的位置，不遮住关键动作、脸部或文字。

## 6. 主体与产品呈现

无IP时没有原角色的脸型、发型、服装与身份保留要求，可自由使用物件、建筑、抽象图形、文字主导画面或普通原创人物，不必出现人物。有IP时保留主要识别特征和原服装的核心配色、轮廓，允许少量时代或风格对应的披肩、扣件、纹样、材质与配饰；同套从首张继承这次设定。角色身份、品牌Logo与普通画面装饰各自管理。

屏幕可以清楚显示内容，不再默认模糊。有真实截图且需要忠实还原时用reference模式；没有截图也能用conceptual模式设计清晰示意UI；不需要屏幕时用none模式。示意界面只表达已确认功能，记录为设计示意，不冒称真实截图。Agent可基于确认的功能列出screen_text，例如“今日任务”“学习进度”；这些是屏幕内部文案，不能借此改写广告主文案或增加未经确认的成绩、价格与效果数字。

## 7. 固化设计层级，再写Prompt

新配置默认art_direction_required=true。每套visual_concepts中保留完整prompt和slot_actions，并增加：

```json
{
  "art_direction": {
    "world": "中世纪启发的幻想藏书室，时代作为美术设定",
    "scene": "石拱窗边的长桌、书架和展开的纸页构成空间",
    "story": "散开的学习纸张被整理成清楚的每日任务路径，表达由只有目标到知道下一步",
    "composition": "纸页路径从前景引向主要学习动作，标题位于自然亮面留白，Logo按规定位置",
    "lighting_materials": "窗光形成纸面焦点，石材、木材与纸张采用所选主画风的统一表现"
  },
  "screen_ui_mode": "conceptual",
  "screen_text": ["今日任务", "学习进度"]
}
```

world和scene可以使用任何适合的设定；story必须来自当前功能事实。prompt将这些决定融成完整画面，不机械堆砌关键词。设计层级完整保存在计划中，供追溯和复核。最终prompt把时代、场景、故事、构图和光色合成一段精炼的画面描述；脚本只结合所选画风、该描述和对应slot动作，不把五层分析原文再灌入生成Prompt。

需要屏幕文字时，每张job保存ui_text，等于本套计划screen_text；调用series_chain.text_rule时传ui_text，保持主文案与屏幕文案各有边界。新增屏幕文案不替代对应slot文案。

## 最终Prompt沿用原结构

仍用原来的参考图说明、画面任务/场景动作、文案层级、视觉体系、资产约束与生成限制等段落。新设计层级是内部推导，不增加五段重复分析；base_prompt_rule已经包含的画风、画面与主体约束不再另写一遍。

常规首张以约800–1200字符、分支约300–600字符为精简目标，按文案与素材复杂度调整，不作为硬性截断线。场景与故事只保留影响成图的决定；每类品牌规则、UI规则和禁止项写一次。分支重点写继承什么、当前文案和动作改变什么。不能为了压长度删掉确认文案、必要参考说明或硬约束。

## 硬约束与效果判断

艺术自由服从本轮用户选择与[固定项](visual-invariants.md)：原版Logo、已确认广告文案与功能事实、字体开关与参考、渠道尺寸和KB、2.5/1K、蓝框阈值、首张依赖、费用与采纳流程保持原合同。硬约束放在Prompt的独立约束段，不让时代或画风覆盖它们。

预检确认设计层级、逐张动作、素材和文案白名单已经进入Prompt。生成后再看画风是否真正可辨、故事能否读懂、画面是否有吸引力，以及品牌和文字是否准确；字段齐全与测试通过不等于审美通过。
