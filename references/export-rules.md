# 图片处理与导出

本机工作台按冻结窗口从完整自然画布裁成精确像素，再用Pillow完成编码和KB校验，保留模型原始PNG。未通过技术规格的图片不能交付；用户可查看不同版本和实际处理记录。

local_app/quality.py负责尺寸、JPEG/RGB、文件大小和哈希检查；local_app/delivery.py只复制当前采纳版本的成品JPEG，不导出原始PNG。套图必须完整并且版本一致，可明确保存已选的合格部分，不要求覆盖全部版位。

图包记录实际图片版本、版位和哈希，按渠道及版位目录保存。相同内容复用图包，新内容保存新版本；旧ZIP不随重出图片改变。产物目录沿用[原目录合同](artifact-layout.md)，具体操作见[本机工作台说明](../本机工作台说明.md)。
