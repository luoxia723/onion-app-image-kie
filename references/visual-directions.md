# 完整画面方案与多样化

新任务默认 `visual_diversity_mode=content_first`。先按确认文案设计完整的场景、动作、情绪和构图，再确定适合的整体画风。脚本保存方案与素材绑定，不再独立抽取画风、布局、镜头、场景和配色拼成画面。

## 设计一套画面

从[Prompt规则](prompt-rules.md)中的创意链出发，先讲清楚学生处于哪个学习瞬间、卡在哪里、产品做了什么，以及变化如何被看见。有IP时，让IP通过姿势、视线、表情和道具参与这个过程；为角色表演与场景关系保留画面空间。

每套由Agent整体编写视觉方案，把人物、道具、光线、配色、镜头和文字的位置放在同一个设计里考虑。小版位仍检查缩小后的可读性，同时保留表达内容所需的动作和空间层次；不要把大字、单一姿势、极简背景当成所有方案的固定构图。

多套可以共用适合IP的画风，通过情境、动作、情绪、叙事视角、构图或视觉隐喻形成区别。只有本轮需要探索其他画法时才改变主风格，不为了去重强制每套换一种画法。用户固定的Logo、IP、字体、渠道与文案仍优先。

例如数学每日任务三图可以分别整体设计“清蓝目标路线”和“暖黄学习手账”，都用适合所选IP的商业动漫表现；三张依次表现准备开始、安排任务、查看完成状态。这里的主题、画风与配色是例子，不是默认模板，也不添加未确认的产品事实。

## 保存完整方案

保持用户保存的制作配置，将每套方案写入 `visual_concepts`。顺序为文案1的全部套数、文案2的全部套数。数组长度等于文案数乘套数。

```json
{
  "visual_diversity_mode": "content_first",
  "visual_concepts": [
    {
      "name": "清蓝目标路线",
      "prompt": "本周开始数学学习的书桌场景。所选IP与练习本、纸卡处在统一的商业动漫视觉体系中，清楚线稿和柔和光影表现角色。浅蓝乳白环境、深色标题与少量暖黄呼应角色服装。主文案在左侧完整留白，角色在右侧略微前倾，视线与手部动作将阅读引向桌面任务；前景纸面与后景形成自然层次，Logo按规定位置保留。",
      "slot_actions": [
        "IP看向数学练习本，握笔、身体前倾，表现想把本周数学补起来、准备开始的状态。",
        "IP把无字纸卡沿目标与基础汇合的路线排好，用整理动作表现每日任务安排。",
        "IP指向今日纸卡，旁边的完成勾选表现学习推进，神态比开始时更轻松。"
      ]
    }
  ]
}
```

- `name` 是方案名称，`prompt` 是完整视觉方案，均不作为额外广告文案。
- `slot_actions` 按图片顺序写每张的动作和情绪，长度等于所选形式的图片数。对应短句仍由 `copy_refs`、`copy_text` 和文字白名单管理。
- 可选 `ip_asset_id` 在配置为随机IP时指定本套角色；用户已固定IP或不用IP时不能覆盖。可选 `font_reference_path` 只能选择原版字体库中的文件，并遵守字体开关。未指定时仍按已保存配置为每套选择IP和字体；整体方案需与最终所选素材协调。
- 用户指定的画风或布局继续保存到 `visual_direction`，其要求优先进入方案。

然后执行，不调用付费接口：

```sh
python scripts/visual_directions.py --config <02_过程/image-config-result.json> --output <02_过程/visual-plan.json>
```

首张Prompt包含 `base_prompt_rule`，其中已经包含图1动作。图2/3的Prompt包含同套 `branch_prompt_rule`，再加入各自的 `slot_prompt_rules["2"]` 或 `["3"]`。清单顶层填写 `visual_plan_path`，每张绑定对应 `visual_direction_id`；首张IP和字体使用计划中的路径。付费前检查整套覆盖、配置指纹、逐张动作与实际素材绑定。同套分支仍只引用本套首张原始PNG。

## 风格库按需参考

[主风格库](style-library.md)保留为创作参考，不是自动抽签池。需要某种画法时检索其具体描述和IP适配，再纳入整套方案；引用的来源ID可保存在该方案的 `style_source_ids`。

```sh
python scripts/visual_directions.py --list-styles --query 水墨 --detail
python scripts/visual_directions.py --list-styles --query "Art Deco" --detail
```

库外画法仍按现有来源与许可要求登记。方案和自动测试只能证明设计意图被保存与执行，实际美感、IP识别和信息可读性仍需看成图。

## 历史任务恢复

原有显式 `open` / `preset` 配置与已保存计划继续支持恢复，不重写其Prompt、素材、指纹或已生成文件。新任务采用 `content_first`；不要为了恢复旧任务，把新的设计字段注入旧配置。付费授权、模型1K、蓝框、候选选择与交付规则继续按各自合同执行。
