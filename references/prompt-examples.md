# 人物、场景与学习痛点的一段式Prompt示例

## 单图·第1张｜半色调网点印刷

生成一张横版应用商店独立广告图，整张采用一个连续完整的场景。以半色调网点印刷画风呈现，用规律可见的网点大小与间距表达主体和物体的明暗，外轮廓采用清楚的印刷线，空间依靠稳定的透视与分区层次建立，表面呈纸张吸墨后的颗粒与色层覆盖关系。画面中的学习者为一位短发、穿浅蓝外套的原创初中女生。学生想在这周补上落下的数学，却在不同章节之间犹豫，拿不准今天先学什么。现代城市清晨，女生坐在公交站雨棚下的宽木长凳上，双脚平放地面，摊开的数学练习册由并拢的双膝承托，不同章节的书签露出页边。后景街道和树影用疏密网点表现，奶油黄晨光、深蓝轮廓与珊瑚红点色构成清楚的印刷层次，主副标题位于画面左侧自然亮面，人物位于右侧。女生左手压住膝上的数学练习册，右前臂轻靠右腿、右手握住手机侧边与底边，屏幕朝向自己，目光停在清晰的第一项今日任务上，眉间仍有些犹豫。镜头从她右侧后方略高处取景，呈现侧脸、握持手机的手与屏幕正面，定格在想补数学、刚找到今天起点的瞬间。屏幕以清晰示意界面呈现“今日任务”、“学习进度”。洋葱AI按目标和基础安排每日任务，支持查看当天任务与学习进度。主标题文字逐字呈现为“这周我想把数学补起来”，作为画面的第一文字层级，按本张构图完整排布。副标题文字逐字呈现为“洋葱AI按目标和基础排每日任务”，字号小于主标题，与主标题形成清楚的阅读关系。在画面底部自然留白处呈现醒目的CTA按钮，按钮文字逐字为“立即体验”，按钮底色与文字形成清楚对比，样式呼应本套画风，与主文案和人物保持清楚间距。左上角原样呈现参考图1的完整Logo，品牌图形与包含“洋葱学园”的全部标准字作为同一完整组合呈现，原版颜色、图文比例、轮廓、眼睛及角标逐项保持一致；以原版整体等比缩放与定位。Logo周围与整幅画面共享连续背景，独立可见边界仅由原版标识自身构成，描边与附属元素逐项沿用原图，完整标识清晰可辨。参考图2仅用于标题字形和排版参考，其中示例字句在本图由确认文案完整替换；标题保持参考中的字体类型、字形骨架、笔画粗细、转折、外轮廓、描边层次、字面宽窄与排版密度，插画画风用于人物与场景，标题采用确定的参考字体体系，文字配色可随画面调整。文字和关键图形与局部背景保持清楚对比；近色或纹理干扰由背景明度、自然留白和布局调整解决，装饰服从阅读焦点。广告正文仅使用本张确认文案，界面功能、说明文字和具体数字均以本轮已确认资料为依据。
