# 一段式Prompt示例

下例为OPPO横版单图、不带IP的设计示例。主画风、场景与文案因任务而变；此处参考图1为Logo，参考图2为字体。本例由`positive_prompt.compose`从方案、素材与文案编排，未调用付费接口。

以蓝晒画风呈现，用感光印相般的深色底与明亮形体建立画面，轮廓边缘保留轻微渗透，细节呈接触印制的自然层次，主体和道具以清楚的正负形关系组织，表面有感光纸的纤维与沉积感。古代书院的拱窗旁，木桌上的纸页旋转成拾级而上的阶梯，引向一部清晰的手机任务界面。窗光透过竹影落在纸阶上，木材、纸张与屏幕形成有意的跨时代组合；左侧自然留白承载主副标题，右侧纸阶与手机构成视觉焦点。几张空白纸卡从散落到整齐排成通向屏幕的任务路径，表现学习目标逐渐成为今天可执行的安排。主体、道具与光线形成统一空间，标题位于清晰留白并具有鲜明阅读层级。屏幕以清晰示意界面呈现“今日任务”、“学习进度”。当前画面的主标题逐字呈现“这周我想把数学补起来”。副标题逐字呈现“洋葱AI按目标和基础排每日任务”，主副层级清楚。左上角完整呈现参考图1的原版Logo，图形、文字、颜色、比例、轮廓及角标与原图一致，周围背景自然延续画面色调，原版标识清晰可辨。标题沿用参考图2的字形骨架、笔画粗细、转折、外轮廓与描边层次，配色呼应当前画面，文字完整清晰。

以本套已生成的第1张广告成图（参考图1）为基础，保持本套画风、场景、主体设定和字体、Logo及其位置，呈现当前文案对应的动作与状态。纸阶尽头的任务卡依次展开，屏幕上的完成标记沿任务路径逐步点亮，表现打开当天任务并查看学习推进。主文案更新为“打开看今天学啥学完看进度”。

角色方案也保持相同写法：在场景与动作中说明实际IP、选定的时代配饰和互动，简短保留其识别特征；不将完整内部推导或不需要的元素清单加入Prompt。技术参数、文案字段和素材绑定留在配置与清单中。
