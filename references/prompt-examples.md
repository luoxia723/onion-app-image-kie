# 人物、场景与学习痛点的一段式Prompt示例

每张都有人物参与。以下单图用原创学生，参考图1为完整原版Logo，参考图2为字体；后续同套分支仅引用本套首张完整广告成图。

**单图 · 第1张**

生成一张横版应用商店独立广告图，整张采用一个连续完整的场景。以蜡画画风呈现，以半透明蜡层覆盖、局部刮刻和温润堆叠塑造形体，主体与道具在柔和层次间清楚浮现，空间由蜡层遮叠和边缘深浅形成，表面保留凝固、擦磨与材料厚度。画面中的学习者为一位穿米白上衣、短发的原创初中女生。她想这周补上落下的数学章节，几本练习册翻到不同页面，却不知道该先补哪一部分。未来幻想学习室里，这位学生坐在有蜡层质感的书桌前，练习册与草稿纸摊开在她面前；桌旁手机清晰展示当天学习任务。她的视线从几本不同章节的练习册转向手机，再沿弧形纸阶落回第一道练习，暖光将人物、书页和屏幕连成清楚阅读路线。米白、蜂蜜黄与湖蓝统一画面，标题位于人物上方的自然留白。学生一手握笔停在练习册上，另一手指向手机中的第一项任务，眉头微松、身体前倾，表现从想补数学却无从下手，到看清今天先做什么、准备开始。屏幕以清晰示意界面呈现“今日任务”、“学习进度”。洋葱AI按目标和基础安排每日任务，支持查看当天任务与学习进度。主标题文字逐字呈现为“这周我想把数学补起来”，作为画面的第一文字层级，按本张构图完整排布。副标题文字逐字呈现为“洋葱AI按目标和基础排每日任务”，字号小于主标题，与主标题形成清楚的阅读关系。左上角原样呈现参考图1的完整Logo，品牌图形与包含“洋葱学园”的全部标准字作为同一完整组合呈现，原版颜色、图文比例、轮廓、眼睛及角标逐项保持一致；以原版整体等比缩放与定位。Logo周围与整幅画面共享连续背景，独立可见边界仅由原版标识自身构成，描边与附属元素逐项沿用原图，完整标识清晰可辨。参考图2仅用于标题字形和排版参考，其中示例字句在本图由确认文案完整替换；标题保持参考中的字体类型、字形骨架、笔画粗细、转折、外轮廓、描边层次、字面宽窄与排版密度，插画画风用于人物与场景，标题采用确定的参考字体体系，文字配色可随画面调整。文字和关键图形与局部背景保持清楚对比；近色或纹理干扰由背景明度、自然留白和布局调整解决，装饰服从阅读焦点。广告正文仅使用本张确认文案，界面功能、说明文字和具体数字均以本轮已确认资料为依据。
