# 学习机基础配置

学习机只有一条流程：输入推广文案与选定版位 → 生成基准图 → 用户查看并确认基准图 → 以确认后的同一张图扩展整套 → 精确尺寸处理 → 按版位叠加Logo。

生成基准图后必须停下来等待人工确认，不自动启动整套扩展。不满意时先调整或重新生成基准图。配置预览只是计划，不是生成的基准图，更不是用户确认。

## 当前可用范围

已实现配置/提示词预览、基准图制作与确认、母版分组并行、单张重出和图包导出。默认“生成演练基准图”全程使用本机演练规划与图片，不调用任何模型；真实制作必须单独明确选择，实际使用所配置服务。自动化验收使用演练和回环HTTP桩；2026-11-13已完成首轮真实套图，像素规格通过，部分视觉偏差仍需修正，详见提示词合同的实际执行记录。旧学习机上传母图直出、普通任务提交等路径不能绕过新流程；已有历史仍可读取和交付。固定项、变量及16组母版提示词合同见[学习机固定提示词](learning-machine-prompts.md)。

- 输入一条推广文案，默认全选44个版位、生成一套。优学派840×404含Logo版位要求两张，所以整套有45张交付图片，基准图不计入交付数量。
- 16组母版中，睿视两个纯画面横幅直接复用已确认16:9基准图；其余15组各图生图一次。全选首轮预计1张基准图＋15张母版＋10次条件自然背景扩展，共26次图片模型调用，不含手动重出。
- IP、画风、字体和参考图按整套确定一次；同一个草稿重复预览保持随机种子和视觉选择，创建新草稿重新随机。
- 基准图是内部16:9视觉图，不绑定某个广告版位，不携带最终广告文案、Logo或CTA。
- 逐版位记录固定正文、CTA、Logo与特殊要求。36个版位有Logo，8个固定无Logo；14个版位有CTA，30个无CTA。CTA默认“点击下载”，可在前端自定义，无CTA版位不绘制按钮或按钮文字。
- 当前所有图片不显示功能名；精选角标和附加文案暂不添加。原精选尺寸保留为普通圆角卡片，与其他正文卡片共用母版。优学派的底部灰色遮罩用代码处理，审核和导出使用同一配置。
- 新输出冻结无框自然背景适配策略：比例差不超过8%轻裁，超过8%由应用AI自然延展背景后精确导出，不再把渐变色块作为成品。提示词内容安全区每侧内缩4%；旧批次原样保留，显式自然适配才创建新图片版本。
- 扩图工作流含代码计算主视觉构图节点：将整个人物/动作/道具组放入普通组10%、超宽组12%的内缩范围，并统一写入基准图、母版和单张重出提示词。镜头退远与整体缩小由原有图生图执行，不增加模型调用；人物完整性仍由用户查看。
- 全部目标尺寸明确记录；尺寸方案使用所选模型支持的比例，记录需要的重构与裁切，并在最终导出时验证精确像素。基础配置验收不代表真实模型生成效果已验收。

学习机配置页依次为“01 文案与渠道 → 02 画面设定 → 03 投放版位”。版位列表默认收起，标题保留已选数量；展开后可修改版位及Logo模板。收起保留选择，遗漏版位时校验会展开选择区域。

## Logo模板

在学习机表单的“配置Logo模板”进入。每个有Logo版位可选现有黑字标准版或白字APP版，拖动位置、输入左侧/顶部百分比及宽度。高度始终按原素材比例计算，模板不能越出画布。无Logo版位不提供启用开关。

默认位置靠近左上角，大小按横幅、横图、卡片分别配置。白字APP版保留原素材的APP标，不是黑字标准版的简单反色。样图仅供位置参考，不充当本次图层叠加结果；临近尺寸样图会明确备注。

模板保存到本机状态目录，使用版本号防止多个窗口互相覆盖，并纳入现有数据库备份文档。计划冻结保存时的模板与素材信息，后续模板修改不应改变旧任务。Logo合成服务仅处理已经达到目标尺寸的图片，输出PNG并核对尺寸；模板保存本身不触发生成。

## 执行、版本与恢复

创建批次时冻结全部目标尺寸、内容开关、母版规则、模型、素材副本、Logo和遮罩参数。第一张完成后停在确认阶段，确认具体版本及哈希后才允许扩套。模拟批次不能改成真实批次，模拟确认不能授权真实生成。

单张重出仅更新该图及其版本列表；基准图重出保留旧成品，重新确认/扩套后才制作新一套。已有未明供应商任务时先恢复查询，不用新基准覆盖其来源。服务重启将当前支持流程的活动制作标为中断，由用户明确恢复；已停用的画幅流程拒绝执行，可沿用基准图新建批次。

失败图片在卡片直接提供恢复按钮。尺寸处理或已完成背景结果的导出失败时显示“重新压缩并导出”，复用当前已生成图片和操作键，不重复生图；未知远端状态仍先恢复查询。透明圆角PNG在体积超限时也可采用调色板编码，保持目标尺寸、透明角和不透明主体；仅在必要时允许颜色及抗锯齿边缘量化。随机噪声等图片仍可能无法在质量、尺寸和KB限制之间兼顾，不能以缩小尺寸或假称完成绕过校验。

已确认基准图还可通过“沿用基准图按新规则制作”创建新批次：保持原IP/画风选择与素材字节，重新冻结当前版位和提示词规则；基准图自身不重生，所有母版（含纯16:9）重新构图。创建动作不自动生图，点击新批次“扩展整套”才使用模型额度。来源有未确认、忙碌、文件损坏或状态不明时明确拒绝。

成品预览直接显示已叠加尺寸/Logo/遮罩/圆角的导出文件，避免重复叠层。全套图片通过尺寸、编码、体积和哈希检查后才能下载ZIP；相同内容复用已有包，旧图和旧包保留。备份恢复支持独立学习机批次与冻结素材，恢复后不自动调用模型。

学习机ZIP按“渠道 / 版位名称_宽x高 / 图片”分目录，例如`百度/广告图_512x512/learning-baidu-512x512_1.png`。渠道和版位来自该批次冻结的规格；有无Logo的同尺寸版位及同版位多张图仍各自保留。根目录`交付清单.json`记录每张图片的包内路径、尺寸、版本和哈希，黑白Logo导出采用相同目录结构。

目录结构标记为`channel-placement-v1`并参与图包复用身份。旧平铺ZIP仍可从历史记录下载；再次保存整套会生成新的分目录版本，不覆盖旧包、不重新生图。新目录下相同图片内容再次保存继续复用同一图包。学习机成品制作多尺寸母版后的PNG图包也使用该结构。

## 并发与资源

图片任务按批次进入全局公平池，与普通任务合计最多20个，等待容量512；画面规划共用1个执行槽，本机压缩/图层合成共用4槽。同时活动的学习机批次最多8个，超额保留配置并明确拒绝启动，不无限创建线程。明确429会暂缓新任务并降低全局并发；已知拒绝可明确重试，未知提交只恢复查询。

状态轮询使用revision，无变化只返回修订号和轻量队列摘要；列表低频刷新，图片校验、网络与本机处理在状态锁外执行。参考素材按内容哈希及账户/上传端点缓存，冻结路径变化不导致同图反复上传。

## 代码入口

- `config/learning-machine-content-rules.json`：44个版位的固定内容规则。
- `config/learning-machine-logo-templates.json`：默认Logo位置与宽度。
- `local_app/learning_pipeline.py`：唯一流程与整套计划契约。
- `local_app/learning_setup.py`：配置保存、参考图校验及预览服务。
- `local_app/learning_runtime_support.py`：完整输入冻结、素材副本、服务端场景填值与恢复适配。
- `local_app/learning_runtime.py`：批次、确认门、队列编排、独立版本与图包。
- `local_app/learning_executor.py`：本机演练及真实服务边界、回执与账户上传缓存。
- `local_app/work_dispatch.py`：共享全局配额、批次轮转、有限等待与取消。
- `local_app/learning_logo.py`：模板保存、固定素材、快照与图层合成。
- `local_app/learning_sizing.py`：模型比例匹配及最终精确尺寸导出。
- `frontend/js/learning-machine.js`：学习机配置与Logo编辑页面。

`GET /api/learning-machine/config` 读取配置；`POST /api/learning-machine/preview` 保存并预览；`PUT /api/learning-machine/logo-templates` 保存Logo模板。预览不创建后台生成任务。

制作接口：`/api/learning-machine/runs` 创建/列出批次；`/{id}/baseline` 生成或恢复基准图；`/confirm` 明确确认版本；`/expand` 扩展或恢复整套；`/outputs/{output_id}/regenerate` 单张重出；`/package` 保存图包。图片和图包通过注册ID下载，不接受任意本机路径。

## 选图制作多尺寸母版

普通已完成图片/完整套图、学习机已确认基准或当前成品可显式选择“制作多尺寸母版”：冻结来源和文字，按内容、剧情及方向分组，每组生成完整自然画布，再从固定窗口导出各尺寸。创建只显示计划，用户启动才调用模型。该入口调用数等于实际分组数，与专用学习机16组加条件背景流程分别计数；具体接口、主体安全区和整组重试见[共用母版合同](shared-master-canvases.md)。

## 当前后台入口

学习机任务从统一制作任务列表打开，详情按基准图、制作进度、成品、图包记录查看。明确点击“确认此图并扩展整套”后先确认该版本再提交扩套。配置预览与基准生成是不同操作，默认本机演练；固定规则、原有版本和图包保持。Logo模板为左侧独立入口，详见[后台UI合同](workspace-ui.md)。
