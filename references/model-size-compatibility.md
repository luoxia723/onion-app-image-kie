# Flare 1K 尺寸比例适配报告

核对日期：2026-10-20。固定模型：`gpt-image-2-5-flare-image-to-image`，固定分辨率：`1K`。参数依据：[KIE](https://kie.ai/gpt-image-2-5)。

本报告按供应商固定比例与最终交付尺寸计算。裁切百分比为居中cover处理预计舍弃的面积比例；因为单轴裁切，也等于该轴舍弃的长度比例。该百分比只用于选择制作分支，不代表白底蓝框模式中的广告内容损失。实际图片像素和比例以返回文件为准。1K是档位，不等于每条边1024像素。

**预计常规裁切达到6%（含6%）使用[白底蓝框生成、OpenCV去框后拉伸](blue-frame-adaptation.md)，生成后由用户查看效果；低于6%常规适配。**这是用户确定的制作阈值，不是渠道官方限制。确认通过候选页的采纳操作完成，不另设Logo配置页。1K原图交付时若需放大至少1.25倍，会追加清晰度提示；不自动升级2K。
