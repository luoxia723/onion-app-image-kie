# Sunburst 1K 尺寸比例适配报告

核对日期：2026-10-19。固定模型：`gpt-image-2-5-sunburst-image-to-image`，固定分辨率：`1K`。参数依据：[KIE](https://kie.ai/gpt-image-2-5)。

本报告按供应商固定比例与最终交付尺寸计算。裁切百分比为居中cover处理预计舍弃的面积比例；因为单轴裁切，也等于该轴舍弃的长度比例。该百分比用于计算原生画布中的保留范围，不等于主视觉内容的损失。实际图片像素和比例以返回文件为准。1K是档位，不等于每条边1024像素。

执行方式更新于2026-11-15：所有普通版位使用[无框自然画布](natural-canvas.md)，按固定安全范围构图并裁成精确像素。表中仍列Sunburst的比例计算示例，不定义其他模型的支持范围。
