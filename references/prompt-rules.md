# 视觉与提示词规范

当前普通广告由`scripts/poster_prompt.py`编译分块提示词；学习机使用`local_app/learning_prompts.py`固定模板。旧一段式示例只解释历史画面方法，不作为新请求入口。上下文分配见[单图与套图合同](prompt-context-contract.md)，学习机另见[模型上下文](learning-image-context.md)。

## 画面规划

先确认当前文案、产品事实、IP、画风、字体及参考用途，再按[艺术定调](art-direction.md)和[画面叙事方法](../skills/visual-scene-planner/SKILL.md)确定具体场景、动作、视线、接触支撑、机位与阅读路线。画面应对应这一张的传播任务，不能只换标题、机械加入手机，或把整套后续情节塞进首图。

只有用户确认的产品事实、功能、界面原文和数字可以作为画面依据。IP保留身份与识别特征，画法和材质适配当前画风；无IP时按当前要求设计原创人物。每套的随机结果在配置时确定并冻结，后续生成不重新随机身份。

普通任务的自然画布范围同时进入画面规划和最终图片提示词。规划阶段就安排中景／中远景、完整发梢和动作道具组，以及可见背景间距；不能先设计贴边大特写，再用一句安全区声明掩盖冲突。

## 最终提示词

普通广告按实际需要编排以下部分：

| 部分 | 内容 |
| --- | --- |
| 任务 | 当前方向、渠道用途、一张连续自然场景 |
| 画面描述 | 当前画风、人物、场景、动作、机位和文案留白 |
| 画面文字 | 当前确认主／副标题与CTA，逐字呈现，不擅自补句 |
| 参考图用途 | 实际编号及IP、字体、画风、构图、真实UI的具体职责 |
| 保持与变化 | 后续张沿用首图的角色、画风、场景和字体，调整当前动作与文案 |
| 画面约束 | 可读性、事实范围、无Logo底图与留位、主视觉安全范围 |

`poster_prompt.compose(config,direction,slot,references)`只编译本张内容，不调用模型。保持完整可执行的画面信息，不做按关键词删句或默认字数截断。广告文案逐字保留，引号用于说明原句，不将引号画入图片。内部版位ID、路径、哈希、缓存、计费、最终KB和导出步骤不发送给图片模型。

主／副标题体现明确层级；双图／三图每张只显示对应短句。CTA取冻结配置，启用时写清按钮文字、造型、对比与间距；关闭时不添加按钮模块。字体参考仅用于字形和排版，样张原句由本张文案替换，不照搬附带贴纸或旧广告内容。

## 素材与Logo

首张仅使用本轮实际选定并冻结的素材；编号以实际请求数组为准。IP用于身份，字体用于标题字形，画风／构图参考用于注明的视觉意图；真实UI仅用于实际产品屏幕，不编造未提供的功能或数字。没有实际素材时，普通任务可用纯白比例辅助图。

新普通任务和学习机都生成无Logo画面。原版黑字／白字Logo由代码在最终尺寸上等比叠加；模型只接收自然背景留位要求，不接收Logo原图。不能让模型重画品牌标准字，也不能把Logo样张当作整幅画风。Logo存在与否、位置、大小和换款见[独立图层](logo-layers.md)。

## 双图与三图

首张是一张完整广告，只承担短句1与当前已启用CTA。第二、三张分别使用自己的短句和具体动作，唯一整景参考为同轮次、同版位、同方案首张原始PNG；第三张也不默认改为引用第二张。后续张保持身份、画风和字体，整体替换旧标题，不重复上传原IP、字体或Logo素材。

执行记录保存首图依赖、来源版本及SHA，恢复沿原供应商请求查询。普通首图重出会按界面说明影响本套后续图；学习机单张重出和共用母版整组重试有各自范围，不共用普通套图依赖。

## 代码与视觉验证

代码冻结模型原生比例、主视觉范围和最终裁框，并负责精确像素、压缩、遮罩、Logo、圆角、版本与图包。当前普通任务不使用蓝框生成、识别或去框，安全区直接描述为自然画布中的可见范围。

成图需要查看错字、可读性、脸手与道具、人物边缘、背景接缝和Logo位置。文件规格和几何夹具通过不能证明模型画对了所有内容。原图、实际提示词、回执与旧版本保留；人工编辑稿和已发送文本分开保存，重新提交仍须保留本轮固定画幅和Logo约束。
