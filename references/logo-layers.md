# Logo独立图层

应用使用用户提供的透明底黑字标准版和白字反白版。原图保存在 `assets/logos/`，运行素材仅裁掉外围透明空白。`local_app/brand_logo.py` 管理普通任务的冻结和叠加，学习机使用 `learning_logo.py` 的版位模板。反白版沿用旧的素材 ID 以读取已保存的配置。

## 新图片与历史图片

新应用商店、信息流任务只让模型画无Logo底图并预留品牌背景。Logo不作为生图参考上传；无IP、字体或用户素材时，使用明确标识的纯白画幅辅助图。无框自然画布按固定窗口裁成精确尺寸后，保存无Logo底图`logo_base`，再按`brand_logo_layer`自动选色和合成。两款素材的字节、哈希、位置和大小按轮次冻结。双图、三图的分支继承无Logo视觉来源，模型仍须输出无Logo底图。旧带框轮次沿冻结记录兼容。

历史图若Logo已经画入像素，没有声明为独立图层的无Logo底图，默认导出保持原样；请求换Logo明确拒绝，界面提示需重新生成无Logo底图。不能覆盖旧Logo后假称替换成功。

新普通任务的手工提示词仍逐字保存发送，但必须保留固定无Logo绘制约束；旧版手工提示词维持其历史合同。编辑器显示固定约束，不暗中改写用户输入。

## 位置与选择

统一Logo模板页提供应用商店、信息流、学习机三个类型及渠道筛选，版位每页8条。学习机默认按横幅、普通横图、卡片分配适度大小，贴近左上角；可改位置和宽度，浅底和深底按钮用于预览。固定无Logo版位不提供启用选项。

普通广告默认采用左上角的尺寸适配留位，喜马拉雅竖图初始配置保留顶部居中。`logo_templates.py`通过`GET/PUT /api/logo-templates`管理各普通版位的素材和几何模板，在现有SQLite文档中保存，revision用于并发保护，备份恢复随索引完成。两款素材共用可容纳两者的落点和宽度。普通任务只设“添加 Logo”或“不用 Logo”，学习机按版位固定有无。

新轮次冻结模板版本和全部普通版位几何；同轮次追加套图与按已有方案重排沿用冻结模板。新建共用母版在创建时读取当前配置。修改模板不回写旧轮次、当前成品或旧ZIP。

`logo_contrast.py`在精确尺寸和遮罩处理完成后，比较两款素材的实际字标像素与下方背景的亮度对比。优先选高对比字标像素占比更高的一款，再比较平均对比。比较只在本机用 Pillow 运行。图包沿用各图片版本实际合成的款式，清单记载其素材哈希。

## 成品验收切换

普通出图、喜马拉雅、学习机和多尺寸适配的当前成品保存了独立 Logo 图层与无 Logo 来源时，卡片和图片详情会显示「切换黑字 Logo」或「切换反白 Logo」。切换优先使用冻结的图层配置和素材。旧学习机图片只冻结了一款时，缺少的款式从当前内置素材读取。工作台本机合成后把款式和成品字节身份保存在本图的 `logo_review`。验收预览和新图包读取同一份文件。切回初选的款式时读取原成品字节。

普通任务使用 `POST /api/tasks/{id}/review-logo`，学习机与多尺寸适配使用 `POST /api/learning-machine/runs/{id}/outputs/{image_id}/review-logo`。请求绑定当前图片版本和已看到的款式哈希。切换保留生图版本与已有勾选，后续重出会为新图重新选色。固定无 Logo、待审核首图和缺少独立图层的旧图没有切换控件。交付记录从已保存 ZIP 读取实际图片。

## 学习机当前成品重新合成

`POST /api/learning-machine/runs/{id}/refresh-logos`接收`idempotency_key`和可选`placement_ids`，省略版位表示当前批次所有有Logo图片。接口使用当前保存模板，直接从无Logo母版本机重新导出，增加输出版本，保留原图片与提示词、母版和旧包。它不调用模型，也不修改整批原Logo快照。处理失败可本机重试，不能引导为AI重出。

每个输出的新模板和素材快照随版本保存；后续重出沿用该输出已应用的图层配置。中断的本机处理按`logo_refresh_pending`提示恢复。

`POST /api/learning-machine/runs/{id}/package`兼容已有 API 调用的`logo_asset_id`参数，值为`learning.logo.black`、`learning.logo.white-app`或省略。选择款式时产生派生PNG与独立图包，当前成品版本不变，已保存派生缓存先核验哈希再复用。

普通任务的`package-preview`查询和`packages`兼容已有 API 调用传入`logo_asset_id`。`logo_export_capability`说明所选图片是否均有可切换底图；旧任务缺此能力时按原图导出。新图包指纹包含实际图片字节与Logo选择，另保留来源候选指纹用于判断当前选择是否已保存。历史图包使用原指纹协议校验。

## 共用母版

“制作多尺寸母版”先冻结可用的无Logo底图，再生成无Logo自然画布；普通旧图若只有烘焙Logo，提示词明确清除旧标志后生成新母版，视觉上仍需检查是否残留。该入口复用最终无Logo母版和固定裁框叠加注册Logo，导出换款不再次生图。普通目标的派生图为JPEG，学习机目标为PNG；不更改来源图片或旧图包，详见[共用母版合同](shared-master-canvases.md)。

## 验证与维护

Logo切换必须验证无模型请求、精确尺寸、固定无Logo图片不变、旧图片/ZIP字节不变，以及两款图包的实际内容不同。无Logo底图、素材与图层记录纳入版本、备份恢复和清理保护；清理不能删掉当前或已交付版本仍引用的底图。视觉效果仍需查看，不把无Logo生成指令当作自动识别结果。
