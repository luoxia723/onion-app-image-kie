# 风格扩展前的固定项清单

整理日期：2026-10-19。本文用于区分不可被风格覆盖的约束、当次配置和可探索项。既有细则以各行指向的owner为准；改变风格不能绕过它们。输出仍需复核；技术约束在配置和代码中执行，影响成图的视觉要求以正向描述进入一段式Prompt，不添加负面清单。写进Prompt不等于模型已被像素锁定。

## 已确认固定

| 项目 | 固定内容 | 依据与执行位置 |
|---|---|---|
| 原版Logo | 使用用户选定的原版资产；图形、标准字、眼睛、颜色、比例和轮廓保持原样，仅调整整体大小和位置。字体参考与Logo角色隔离。 | 用户已选择原版；[Logo规则](prompt-rules.md)、`scripts/logo_reference.py` |
| 前景与背景可辨识 | Logo、需阅读的文案与需识别的关键图形，在任何配色下均须与所在局部背景形成足够对比，在目标尺寸下清晰完整。颜色或明度过于接近、纹理干扰和遮挡均应处理，不仅检查黑字或白字。通过背景、布局与非品牌文案配色解决；Logo保持原版，不另加描边、独立底板、色块、边框或弧形区域。 | 用户本轮明确补充；[对比与资产规则](prompt-rules.md) |
| Logo位置 | 喜马拉雅720×1280和720×1559在广告范围内上方居中。其余版位沿用左上角默认；其他位置必须有本轮明确指示且符合渠道要求。 | [当前渠道规则](channel-placement.md)、`logo_position(config)` |
| 确认文案与产品事实 | 使用已确认文字，保留必要文字和标点；风格模板不得添加旧示例口号、数字、按钮、功能、价格、提分承诺或无依据效果。 | [Prompt规则](prompt-rules.md)、[视觉边界](visual-compliance.md) |
| 当前渠道范围 | 仅当前表的8个渠道、19种尺寸与形式。按单张宽高、格式、体积上限和图片数执行；旧102版位保持停用。 | [当前渠道规则](channel-placement.md)、`config/channel-placement-rules.json` |
| 大比例差距适配 | 预计常规cover裁切达到6%时，白底蓝框内生成完整广告、框外纯白；OpenCV识别实际框线后去框、拉伸到目标尺寸。低于门槛常规适配；不叠加已废弃的百分比留白段。 | 用户已确认；[蓝框适配](blue-frame-adaptation.md) |
| 屏幕与UI | 允许清晰示意UI；要忠实还原实际界面时使用真实截图。示意UI不冒称真实截图，不添加未经确认的成绩或功能事实。 | [视觉边界](visual-compliance.md) |
| 人物与学习痛点 | 每张都有学习者：选定IP或普通原创学生。动作、表情、具体学习处境与当前文案对应；产品帮助来自确认事实。 | 用户当前明确要求；[艺术定调](art-direction.md) |
| 信息清楚、画面不杂 | 风格变化服务当前文案；标题、Logo和关键内容保持完整可读，不被装饰、纹理、人物或裁切遮挡。用户已明确要求画面不要太杂。 | 用户本轮要求；[Prompt规则](prompt-rules.md) |

前景／背景可辨识是我们的制作要求，不把外部网页无障碍规范中的某个对比率数值误写成渠道对Logo的硬指标。同色系可通过足够的明度与层级差异获得可读性；辅助背景与装饰可低对比，不能因此让全图所有元素都变得抢眼。当前尚无可靠的Logo定位、像素保真和前景／背景可读性自动质检，需结合目标尺寸预览人工查看。

## 当次配置保存后固定

- 本次选用的Logo版本、IP身份、字体参考、真实UI及其角色。IP脸型、发型、体型、年龄和关键标识保留，原服装核心配色和识别轮廓保持可辨；允许少量对应画风或时代的纹样、材质、披肩、扣件或配饰。无IP时使用普通原创学生，每张仍有人物参与，不套用品牌IP身份与服装要求；物件、建筑和文字辅助学习场景。Logo仍独立保真。
- 本次已确认的文案、CTA、渠道版位、图片形式、套数和费用范围。双图/三图仍是2张/3张独立图片，按slot使用对应短句。
- 启用字体参考时，示例文字由本张确认稿完整替换；主标题保持其字体类型、字形骨架、粗细、转折、轮廓、描边、字面宽窄与排版密度，字体体系与插画画风分别管理。参考PNG不是字体文件，不保证像素级复刻。
- 同一套图的视觉体系应协调。图2/3仅引用同套首张PNG，从首张继承角色、字体与配色，按对应文案改变状态；不能用重复提示词替代真实图片引用。

配置可以在新任务或新版本中由用户改变，不应写成永久品牌限制。当前Flare图生图、1K、参考图数量等执行参数分别由[供应商合同](provider-contract.md)和脚本维护；3积分/张是当前预算依据，不是外部计费保证。

## 可以探索，不写成永久限制

整体视觉体系、世界与时代、地点、故事、布局、主视觉类型、普通人物/道具、镜头、动作、材质、光线、背景处理与配色，均可在上述固定项内探索。古代、中世纪、现代、未来与幻想设定都是开放选择，不限于学习桌。蓝框只限定可用范围，不规定框内必须是某种构图。

近期“蓝白商业动漫、黑发学生、蓝色连帽衫、学习桌、圆点线索”是试图选择，不是永久模板。也不把某个风格的惯用文字、小字、标签、符号或人物自动搬进我们的广告。

全画面是否必须始终以蓝白为主，用户尚未明确要求；不得自行把近期样例的配色写成永久限制。任何候选配色都先满足Logo原版与背景对比的固定项。

## 编排与效果验证的边界

[完整画面方案](visual-directions.md)由Agent先设计内容、IP动作与整体视觉，再保存可复核的计划；脚本检查计划、逐张动作与实际Prompt、所选IP和字体的绑定。批量默认按套随机主画风并优先不重复，同套继承首张；用户指定画风优先。风格描述及来源仍由config/visual-directions.json、config/visual-style-sources.json维护，供整体设计时按需参考。

当前没有Logo像素保真、前景背景可读性或生成画风一致性的自动图像检测。计划不同不代表成图必然不同，Prompt规则仍需在候选中逐张查看。内容偏差按[候选选择规则](input-output-contract.md)记录，不自动新增付费任务。
