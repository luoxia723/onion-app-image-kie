# 图片制作后台

工作台沿用现有后台布局，使用原生 JavaScript、Python 本机服务和 SQLite/文件记录。

`frontend/css/workbench-ui.css` 统一侧栏、页签、表格、状态、操作菜单和图片预览的样式。侧栏和这些控件沿用 BeUI 的公开组件样式，上传区也采用 File Upload 的点击和拖放交互。许可位于 [BEUI-LICENSE.txt](../frontend/BEUI-LICENSE.txt)。

## 导航和任务入口

左侧为制作任务、Logo模板、交付记录、模型与设置、数据维护。启动默认进入任务中心，草稿也是列表记录；打开页面不会自动创建草稿或提交模型。新建时仍读取服务端记忆的形式/渠道配置。导航可收起，当前端口与本机连接状态按实际页面显示。

`workspace.js`负责全局页面、列表与查询状态；`production.js`负责制作阶段和图片详情的展示；`app.js`、草稿和提示词模块继续处理现有请求、并发门禁和编辑保存。页面或阶段切换只改变查看范围。

普通任务、独立学习机批次、共用母版仍分别保存，用来源类型与ID识别。任务中心可跨类型搜索并分页，不能把几个来源各自的第一屏拼成“全部”。

任务和交付记录每页10条，固定显示上一页、下一页、当前页和总页数；只有一页时禁用翻页。表格在页面内滚动，分页位于表格下方。轮询读取当前游标页，不返回第一页；筛选重置第一页，读取失败保留当前记录，删除末页最后一条后回退到有效页。

任务行操作菜单按视口定位，空间不足时向上展开，避免被表格滚动容器裁挡；滚动时跟随锚点，锚点离开视口、点击外部或按Escape关闭。菜单和重命名期间暂停列表轮询刷新。

## 制作页面

- 配置依次为文案与渠道、画面设定、投放版位。学习机版位默认收起，显示已选数量；缺少版位时校验会展开并定位。
- 学习机的画面来源位于文案与渠道。概念图和画面设定里的参考图都可点击选择或拖入。上传概念图显示横向 16:9 缩略图和无 Logo 说明，手动输入图上正文与可选按钮字。扩版方案按处理方式展示版位和预计模型调用。概念图就绪后可进入原确认页查看并扩套。
- 学习机主操作是「生成基准图」或「查看并确认概念图」。正式制作使用配置好的规划和图片 Key，「仅预览计划」可离线检查配置。普通任务的图片模拟属于图片设置。
- 学习机详情分基准图、制作进度、成品、图包记录。用户明确点击“确认此图并扩展整套”后，先调用确认接口，再在版本/模式/哈希仍一致时调用扩套；普通确认接口本身不会隐式扩套。
- 共用母版详情以来源与计划代替新基准图，创建计划不生图，用户启动后才调用模型。独立母版整组重试仍只适用于这个入口；专用学习机使用现有批次级恢复和单张重出。
- 普通任务按完整候选套图预选，可一键全选当前版位的合格套图，保存时检查完整性和硬规格。学习机和多尺寸适配按当前成品逐张确认，选中本批次所有成品后可导出整套。
- 「喜马拉雅套图」与微博粉丝通、CPA 同列在信息流的投放版位。勾选后全选五个尺寸，可逐项取消。方图优先作为首图，取消时改用第一个已选尺寸。通过审核后只生成其余已选尺寸。界面区分后台查询、自动重审和本机导出。扩展图可单独重出。混合任务的成品目录把喜马拉雅列为一组，选齐当前成品后可单独导出该套，或和其他已选成品一起保存。
- 成品按冻结渠道归组，图片保持原比例，正文和 CTA 标签取冻结规则，完成的成品显示实际合成的 Logo 款式。母版有字审核的状态在制作进度显示，疑点可直接打开原图、复核意见及修复候选。人工确认或重试审核绑定当前版本与图像哈希。
- 已完成的有字母版可在图片详情选择「确认字形问题并清修本组」。这一动作确认可见文字问题，提交一次 Nano Banana 清修。复审通过后更新同组版位，保留旧版本。
- 去正文或按钮的母版未通过构图审核时，图片详情显示「重新构图本组」，沿用同一来源和版位。旧版本保留。
- 失败卡片直接显示恢复按钮，不把主要重试藏进更多菜单。背景步骤已经完成、只待本机导出时，服务端返回`recovery_action=retry_export`，按钮为“重新压缩并导出”，沿原任务键处理而不生图。无成品卡片使用紧凑占位，不按目标比例撑出大块空白；历史版本不提供重试。
- 学习机和喜马拉雅的审核工具栏在浏览时保留已选数量、全选、取消全选和整套导出。全选覆盖当前批次或当前套内所有已完成的版本。标签页内刷新保存勾选，单张重出后只需重新勾选变化的版本。
- 已完成成品的“重出本图”与“查看详情”并排常驻，背景调整也直接显示；历史版本、未确认基准或批次忙碌时禁用。失败卡片沿用明确的恢复按钮，不另外提供会绕过恢复的重出入口。卡片与图片详情复用相同按钮及门禁，详情按钮位于提示词正文之前。
- 共用母版的重扩/恢复查询直接显示在进度表对应行，说明会更新整组尺寸；历史母版详情不可重扩。专用学习机的失败母版提供批次恢复入口，不伪装为不受支持的单组重出。应用当前Logo模板直接显示在交付区，说明作用于本批次有Logo的成品。
- 普通图片卡片与进度行可直接重出，首图按钮说明后续图范围；图1依赖、未知请求和本机适配按原规则分流。卡片沿用当前实际提示词，编辑稿仍在详情中使用。提交前锁定操作并传递当前图片版本，防止连续点击重复提交。队列暂停/继续/停止、图包检查并重新保存和混合选择清空无需打开更多菜单。
- 普通出图、喜马拉雅、学习机和多尺寸适配共用 KIE 状态和恢复动作。相应卡片、制作进度和当前图片详情按后端判定显示查询、接回任务或核对指引。回执缺失或无法读取时显示核对 KIE 记录、恢复备份的指引。

## 图片与图层

普通成品挑选将任务信息、阶段页签与任务操作合并到顶栏。版位和筛选使用紧凑行，底栏显示选套统计，提供切换版位和保存。普通单图候选在宽窗口并排，短窗口可继续纵向浏览。喜马拉雅整套和学习机同一渠道的混合比例成品从上往下查看。超宽图独占一行，其余图片在宽窗口可并排，窄窗口使用单列。图片保持原比例，尺寸、状态和操作紧贴图片。

点击喜马拉雅图片在工作台内打开成品或当前待审核的无 Logo 候选。套内缩略图和左右键可查看有图的尺寸，审核状态、成品勾选和恢复动作位于右侧。「导出整套」与成品详情的单张下载各自独立。

普通图片详情默认显示该版本实际提示词，编辑草稿另外展开并自动保存；使用草稿重出时明确标注。历史版本只读，重出影响范围仍遵守首图/分支规则。学习机实际提示词仍按所选图片版本只读查看。

普通和学习机详情提供适应窗口与 100% 像素显示。放大后滚动查看文字、描边和圆角。学习机成品和母版可用左右键查看当前范围内有图的记录。

学习机和多尺寸适配页面只渲染当前页签，切换页签时读取当前批次状态来展示对应内容。图片详情独立于页签内容渲染。

原图、成品、最近版本对比、参考素材和处理记录各有清楚入口。本机去框/整图适配和恢复查询不伪装成新的AI生成。切图前保存编辑稿，保存失败保留当前编辑内容。

Logo模板页按应用商店、信息流、学习机分类型，并提供渠道筛选、搜索和每页8条的版位翻页。使用完整黑字标准版和白字反白版原始素材，位置/宽度等比并限制在目标画布内。学习机固定无Logo版位仍不可启用；普通任务只指定是否添加 Logo，版位固定有无优先。跨普通/学习机配置类型前需保存或重新读取，避免丢失编辑。

工作台逐图比较落点字标的对比度，选用黑字或反白。普通模板保存在现有SQLite的`ordinary_logo_templates`文档中，通过`GET/PUT /api/logo-templates`读写并以revision防止覆盖其他窗口。新轮次冻结全部普通模板，追加套图和方案重排沿用该轮次快照；新建多尺寸母版采用创建时配置。旧图片和图包不自动应用新模板。

模板用浅底黑字和深底反白示意位置。图包直接使用成品上的 Logo，历史图包保留其实际款式。

有独立 Logo 图层的当前成品，可在卡片或大图详情一键切换黑字和反白。工作台保存验收款式，沿用本图原有勾选。新图包和单图下载使用验收预览上的款式。

## 只读聚合接口

| 接口 | 用途 |
|---|---|
| `GET /api/workbench/items` | 普通任务、草稿与制作批次的统一摘要，支持q/kind/state/cursor/limit |
| `GET /api/workbench/packages` | 已有图包的统一记录，支持q/kind/cursor/limit |
| `GET /api/workbench/packages/{task或run}/{来源ID}/{图包ID}` | 读取已保存ZIP的清单，不使用当前候选图替代 |
| 上述路径加`/images/{序号}` | 验证后读取该ZIP中的实际图片 |

游标绑定搜索/类型/状态，按更新时间与稳定来源键排序。显示的格式来自冻结输出规格，历史学习机PNG不误记成普通JPEG。

图包预览使用有界内存缓存减少相同ZIP反复完整校验，缓存身份包含记录指纹、文件路径、大小、修改/变更时间；文件变化重新验证。每张取出的图片仍验证清单SHA和实际编码。正式下载继续走原来源接口，保持原有完整校验。列表不发起生成、选择或确认。

## 设置、维护和恢复

设置与数据维护改为完整页面。Key不回显，留空保留，连接测试仍是明确动作。设置保存期间锁定表单快照；切换页面后迟到响应不重绘新页面。全局页面URL不携带旧任务/草稿ID，刷新不会跳回旧任务。

备份、恢复、清理的原有范围和必要确认保持。页签、筛选、模板背景等展示状态不写入图片版本。资料冻结API继续保留，当前设置页没有产品资料编辑控件。

## 验证与维护

测试加载正式workspace/production模块；旧“高级折叠”、任务侧栏和启动自动打开草稿等布局预期按新导航更新，保留请求门禁、版本、恢复、选择和旧图包保护。聚合接口测试覆盖全范围分页、来源路由、未确认基准、历史PNG和实际ZIP读取。

浏览器验收使用独立状态目录与离线规划/图片替身，验证真实本机HTTP、确认/扩套、导出和设置流程，不使用用户Key或模型额度。还原基线、截图及几何报告保存在工作目录`UI整体重构/2026-11-15-正式还原/`。视觉稿是布局依据，正式控件与图片均来自代码和原始资源。
