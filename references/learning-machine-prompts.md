# 学习机固定提示词与变量合同

学习机使用一张16:9视觉基准图，经用户查看并确认后，按16组固定规则扩展母版，再导出44个版位的45张PNG。优学派840×404的两张允许共用同一画面，不增加AI母版。配置预览只编译模板；独立制作入口在明确模式下执行。本机演练不调用模型，真实模式按用户动作调用。首轮真实出图验证与已发现的视觉偏差见文末实际执行记录。

## 哪些固定，哪些改变

| 类型 | 内容 | 谁决定 |
|---|---|---|
| 固定流程 | 基准图→人工确认→母版→本机导出；所有母版独立引用同一张确认基准图 | 代码 |
| 固定画幅 | 基准图16:9，16组母版各自的生图比例及普通/超宽布局 | `learning-machine-master-groups.json` |
| 固定交付规格 | 每版位精确宽高、PNG、文件大小、圆角、遮罩和Logo有无 | 当前版位内容规则 |
| 固定内容开关 | 是否出现正文和CTA；全部功能名关闭，精选及附加文字暂不添加 | 16组内容类型及版位规则 |
| 当前文字输入 | 一句用户正文和统一CTA文字 | 不需要额外输入功能名或精选补充文案 |
| 每任务变化 | 用户推广文案、CTA文字、补充画面要求、参考图、所选IP/画风/字体 | 用户输入；CTA默认为“点击下载” |
| 每套只确定一次 | 随机选项的实际素材、视觉配置、第一张的场景与实际成图 | 代码抽取一次；第一张场景规划节点产生画面方案，用户确认实际基准图 |
| 单张重出 | 所请求输出的版本及可选局部修改 | 始终使用本套确认基准图和该版位规则；不覆盖母版、不更新兄弟图 |
| 后处理配置 | 黑/白Logo素材、位置、大小；其他固定图层 | 本机模板；模型不画Logo、角标或可见占位边框 |

“没有IP”表示不绑定固定IP素材，不等于不能出现画面方案需要的普通人物。“没有字体参考”不等于禁止正常广告文字。文字有无始终由内容规则决定。

## 第一张与后续母版

第一张的模板只把推广文案作为画面主题，结合确认产品事实、IP、画风及不同用途的参考图，安排一个清楚、成立的瞬间。第一张不排功能名、广告正文、CTA或Logo。具体场景、动作、物体关系和机位由首张画面规划节点提供；配置预览中该方案尚未产生；开始制作后由服务端规划并验证，再填入基准图提示词。模拟模式使用明确标识的演练方案。

后续母版不再次发散策划。代码合并通用视觉继承要求、对应内容白名单、固定比例、安全区和图层约束，生成固定结构的提示词。后续每次模型请求的参考图1都是本套已确认基准图；它是唯一整景、角色身份和画风图像依据。不再次上传原始IP、画风海报或构图参考，避免带入旧人物、旧文案与CTA。只有真实UI和文字分支的字体素材按狭义用途保留并重新编号；不引用上一组母版串联生成。

各节点的输入、输出与模型上下文边界见[模型上下文合同](learning-image-context.md)。图片提示词只保留画面、素材用途、直观百分比范围和准确文字；渠道ID、依赖、缓存、版本、导出参数与素材绑定JSON保存在代码记录，不发送给模型。

## 三种内容指令

| 内容类型 | 必须出现 | 必须去掉 |
|---|---|---|
| 纯画面 | 基准图主题和关键视觉 | 功能名、广告正文、CTA文字和按钮形状 |
| 正文，无CTA | 用户正文，逐字准确 | 功能名、独立CTA、按钮形状与额外下载引导 |
| 正文＋CTA | 用户正文、用户CTA文字及按钮 | 功能名和未要求的其他营销句 |

无CTA并不删除用户正文中本来就有的“下载”等文字，只是不额外增加独立按钮或引导。所有图片都不生成Logo、精选标、精选底部补充文字及ONION等装饰品牌字。旧样图中的功能名不作为当前内容要求。

### 主视觉构图节点

这套处理封装在实际工作流中，不依赖人工逐张改提示词：基准图确认 → 代码计算各组主视觉范围 → 使用带约束提示词图生图 → 精确尺寸与图层导出 → 用户查看完整性。`learning_prompts._framing_contract`产生冻结的`main_visual_framing`，`_framing_prompt`统一写入基准图、分组母版和单张重出提示词；运行时按冻结版本传给执行器。普通组在避遮罩保留框内每侧内缩10%，超宽组12%，文字仍独立使用4%边距。当前值为构图初始规则，不是自动识别结果。

主视觉指主体、动作肢体与关键道具组成的完整叙事组，不只保护脸。提示词要求镜头退远、整体缩小重排，补全参考图已有截断；人物半身构图保留完整发梢、头肩到腰部、双臂手肘和双手，不沿用参考大特写的裁边。无人物则保护主要物体，不额外添加人物。例如E7组从3:1适配到1400×340，主视觉允许的最大高度约为母版55.37%，上下各有约22.31%自然背景，用于保留裁切空间。

计算节点不调用AI，不增加原有1+15图片调用。提示词中的画面缩小和重构由原有图生图完成；代码负责几何和导出，不虚构已完成的人物检测，也不暗中新增AI审核或接缝重绘。配置预览会展示这条扩图子流程；旧批次保持其冻结提示词和裁框。

新编译输出冻结`sizing_policy=natural_if_needed`：面积比例差不超过8%轻量裁切，超过8%调用带目标构图草稿的AI自然扩展背景，再精确导出；不把渐变色条作为成品。背景提示词只接原始画面、目标构图和准确正文/CTA。旧`preserve_source`批次仍可读，只有显式自然适配操作才升级图片版本；实际请求、回执和旧图包不改。完整流程见模型上下文合同。

底部遮罩由代码按同一模板叠加到审核画布和最终PNG。当前用户确认的是底部淡灰渐变效果，初始参数为底部高度28%、最深不透明度42%、黑色线性渐变；这些是视觉初始值，不是原表官方尺寸。最终顺序为精确尺寸→底部遮罩→Logo→圆角。没有启用遮罩的版位不添加灰层。不会把旧样图的右侧平色块当成当前遮罩需求。

模型不支持某组固定比例时，预览标注不支持，不偷偷改比例或模型。分辨率另行配置，最终像素由代码精确核验。

## 实现与边界

- `config/learning-machine-master-groups.json`：固定分组、比例、内容类型及产品文字默认配置。
- `local_app/learning_prompts.py`：离线模板编译、素材用途绑定和单张重出提示词。
- `local_app/learning_setup.py`：保存配置时附上16组提示词、母版复用关系和调用计划。
- `local_app/learning_sizing.py`：使用固定母版比例计算裁框，最终导出精确像素。
- `local_app/learning_mask.py`：可冻结的底部灰色遮罩配置与代码合成。
- `local_app/learning_output.py`：独立的新导出链，叠加遮罩、Logo和圆角，不带旧精选标。
- 前端“仅预览计划”→“查看固定提示词”：查看本任务实际填值后的基准图和母版提示词。
- 制作结果按冻结渠道分组；点击基准图或成品，在图片详情中查看所选版本实际提示词、复制和母版来源。历史提示词与当前配置预览分别保留。

全选时16组母版中，B1直接复用基准图，仅15组需要新的图生图；预计首轮图片模型调用为1＋15＋10＝26次，其中10次为按当前规格计算的条件背景扩展，不含后续手动重出。提示词固定不代表模型结果逐像素相同，也不代替成图验收。自动化验收使用本机演练图片和回环HTTP请求；真实出图单独按用户授权执行，确认始终是用户针对具体图片版本的动作。

## 实际执行记录

每个批次保留完整冻结模板、服务端画面方案、模型实际收到的提示词与参考绑定、供应商回执和版本文件。无图片参考的基准图请求使用代码生成的中性画幅辅助图，并记录实际追加的用途说明；它不充当用户参考或已确认基准图。后续图始终绑定本批次已确认基准图。

2026-11-13首轮真实全选验证已生成45张PNG并通过精确像素、体积与哈希检查。视觉复查发现原始风格海报对A1/E5产生干扰，部分超宽图又因固定居中裁框损失内容；这些旧成品不视为全部视觉合格。上述参考隔离、量化内缩及保全原图策略是在复查后新增，未重写这次实际请求记录，也未自动付费重做。

## 选图制作多尺寸母版

普通已完成图片/完整套图、学习机已确认基准或当前成品可显式选择“制作多尺寸母版”：冻结来源和文字，按内容、剧情及方向分组，每组生成完整自然画布，再从固定窗口导出各尺寸。创建只显示计划，用户启动才调用模型。该入口调用数等于实际分组数，与专用学习机16组加条件背景流程分别计数；具体接口、主体安全区和整组重试见[共用母版合同](shared-master-canvases.md)。
