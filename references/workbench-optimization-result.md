# 整体优化实施与验证记录

2026-11-02。整体方案四批内容已落地，运行方式仍是本机网页、一个Python后台、SQLite和本地文件，运行依赖未增加。

## 已完成

- 统一规划与图片调度：任务轮转、全局并发即时生效、暂停与继续不改变图片版本。新安装默认并发4，保留现有用户设置。依赖未就绪不提交后续图，恢复查询不重复生图。
- 增加任务修订号和兼容读取，旧数据库升级前自动备份。历史任务不再按保存满7天删除，归档和删除分开，清理暂存文件保护任务、版本和草稿引用。
- 任务列表只返回摘要，当前轮次及预览详情按需获取；未变化不重建页面，空闲/隐藏窗口降低轮询频率。实际数据中的列表请求由约488 KiB降至747字节；当前轮详情约31 KiB，不含完整提示词。
- 侧栏显示正在处理、待处理、历史，草稿单列。轮次显示编号、模型、形式和可用的创建时间；历史缺失时间不推造。
- 展示真实上传、提交、生成、下载和处理阶段。全局队列概览显示并发占用、排队、依赖和暂停数量。版位覆盖提示改为普通信息，不要求全部版位选满。
- 提示词草稿独立持久化，按图片版本与编辑窗口保留，不覆盖生成图片的实际提示词。多个窗口保留的草稿可以选择；旧窗口提交时检查图片版本，避免覆盖更新后的结果。
- 预览提供历史图片版本和实际参考，旧版本只读；可以对比最近两版。停用素材在历史参考中注明，不删除原文件。旧版本自由拼套未开放，避免首图依赖不一致。
- KIE适配器使用显式请求/上传依赖，不再在工作进程中临时改写全局函数；上传缓存用可随进程退出释放的文件锁，并按素材协调上传。
- 打包、下载传输、本机图片处理移出全局状态锁。图包使用选择快照，保存期间其他选择不会被回写覆盖；同一任务的相同选择并发保存复用图包。
- 收拢前端重复函数。模型选项由后端统一注册信息提供；继续支持GPT Image 2和GPT Image 2.5 Sunburst，均为1K。
- 更新双击启动完整性检查、说明文档及无Key源码包。

## 验证

完整Python测试315项通过；前端测试26项通过。新增验证覆盖队列轮转、运行时并发、暂停继续、摘要及修订号、编辑窗口草稿隔离、历史版本参考、归档与清理、锁外打包及同时保存、旧数据库备份与恢复、HTTP按需读取。

浏览器在隔离模拟环境验证：打开已保存任务、编辑关闭后恢复、两个窗口独立草稿、历史只读版本、交付入口和归档。正式环境只做读取检查：4轮66张图片的原提示词、参考、版本、路径和原交付包保持一致；原图和成品文件存在，原图包通过规格校验。

本次优化未新增付费规划或生图调用。既有真实GPT Image 2与2.5的结果保留。新Windows实机与长期高并发实测未包含在本次验证中。
